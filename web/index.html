Selected Models: V1, V5, V6 and Latest

  • V1 — Baseline: Reference for measuring improvements.
  • V5 — 1 km surrounding features: Best PR-AUC of V1, V5 and V6 (0.5159) and 86 top-100 hits.
  • V6 — Pedestrian accessibility: Lowest deviance of V1, V5 and V6 (0.4205).
  • Latest — V5 + V6 (production): V5's 1 km features plus V6's walkability features, without population density. Deviance 0.4176, PR-AUC 0.5194, 86 top-100 hits, 120 candidates.

The differences are relatively small. The heatmaps below use the same held-out predictions as these metrics (web/metrics.json).
